## Latin parser

Uses latindictionary.io API to get words and their definitions from Latin text 
and turn them into a spreadsheet.

Open the html file in a browser. There is a text box to enter Latin text, and 
buttons which then call latindictionary.io API to get the words and their 
definitions from the text. The results are either output as a TSV which can be 
imported into a spreadsheet, or displayed on the screen in a table which can 
then be copied and pasted into a spreadsheet.
